1. One-shot

0 stops

For when it's baked. You're done discussing, you just want the finished brief. Saying it is your approval, so I never stop to ask.

Say (short)
"build it out""send it""now build it""run it through"
Full prompt it's equivalent to
Build this into a full creator brief. Run the entire brief-build sequence end-to-end, steps 1-7, visibly - message engine, format + double-test, variables, hook scoring, script, the pre-doc assembly checklist, the 27 gates (quote the lines), gate 8 loser-check - and finish by running check_brief.py until it prints PASSED. Don't enter mid-pipeline, don't skip any conditional section. Do NOT stop for approvals - I've already approved; deliver the finished validated brief in one pass.

2. Default

1 stop

For a normal build. You want to approve the overall direction once - engine + format + hook as a bundle - then let me run to the finish.

Say (short)
"build the [concept] brief""let's brief this"
Full prompt it's equivalent to
Run the full visible sequence + all gates + validator, but stop ONCE after locking the engine + format + hook for my yes, then build straight through to the validated brief.

3. Step-by-step

5 stops

For when it's half-baked. You want to shape each piece as we go, catching a wrong turn at step 1 instead of after I've built on top of it.

Say (short)
"let's go step by step""walk me through it""one step at a time""start from step one"
Full prompt it's equivalent to
Build this into a brief, one pipeline step at a time. Run step 1 (message engine), show it, then STOP and wait for my yes/no before step 2. Repeat for every step - format + double-test, variables, hook scoring, script - pausing for my approval each time. Then run the assembly checklist, the 27 gates, gate 8, and check_brief.py to PASSED. Show everything, skip nothing.
One steering word for any mode: say plan at any point - mid-build, whenever - and I stop and show you the full checklist with exactly where we are. Your "are you on track?" button, no need to know the steps yourself.
